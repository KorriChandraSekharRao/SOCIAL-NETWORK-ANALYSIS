# Social Network Analysis Project

## Overview

This capstone project focuses on analysing complex social network structures using principles from **Graph Theory**, **Network Science**, and **Social Network Analysis (SNA)**. The project aims to study interaction patterns, identify influential entities, detect communities, and extract meaningful insights from network data.

The project applies computational and analytical approaches for understanding social structures by transforming interaction data into graph representations and evaluating network properties using established graph metrics.

---

## Objectives

- Understand and analyse the structural characteristics of social networks
- Identify influential nodes using graph centrality measures
- Detect communities and relationship clusters within networks
- Study connectivity patterns and interaction behaviour
- Visualise network structures effectively for interpretation and analysis
